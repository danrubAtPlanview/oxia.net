# Maintainers

This file lists the maintainers of oxia.net, an unofficial community .NET port of the [Oxia](https://github.com/oxia-db/oxia) Go client.
This project is **not** part of, endorsed by, or maintained by the upstream Oxia project (see [Relationship to upstream](README.md#relationship-to-upstream)).

## Current maintainers

| Maintainer | GitHub ID |
|---|---|
| Repository owner | [danrubAtPlanview](https://github.com/danrubAtPlanview) |

The maintainers review and merge pull requests, triage issues, cut releases, and act as the security response team described in [SECURITY.md](SECURITY.md).

## Becoming a maintainer

Maintainership is earned through sustained, high-quality contributions: ports of upstream changes that keep the `PORT NOTE` / test-parity discipline of [DESIGN.md](DESIGN.md), reviews, and help to other users. A current maintainer may invite an active contributor; the invitation is recorded by adding the person to this file and to [`.github/CODEOWNERS`](.github/CODEOWNERS).

A maintainer who is no longer active is moved to an "Emeritus" section at their own request or after a long period of inactivity, with thanks.
